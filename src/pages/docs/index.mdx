# Documentation

Welcome to the OpenAuthster documentation. Learn how to deploy and integrate multi-tenant authentication into your applications.

---

## What is OpenAuthster?

OpenAuthster is a **multi-tenant authentication system** built on [OpenAuth](https://openauth.js.org/) for **Cloudflare Workers**. It provides:

- 🔐 **Issuer Server** - OAuth 2.0 / OIDC authentication at the edge
- 🏢 **Multi-Tenant** - Manage multiple projects from a single deployment
- 🎨 **Web UI Dashboard** - Configure themes, providers, and projects
- 📦 **Client SDKs** - TypeScript client with React integration
- ☁️ **Edge Deployment** - Global low-latency on Cloudflare's network

## Architecture

OpenAuthster follows a modular architecture:

```
┌─────────────────┐
│  Your App       │
│  (React/Next)   │
└────────┬────────┘
         │ Uses OpenAuthsterClient
         │
         ▼
┌─────────────────────────────────┐
│  OpenAuthster Issuer            │
│  (Cloudflare Worker)            │
│  • Multi-tenant auth            │
│  • OAuth providers              │
│  • D1 Database                  │
└────────┬────────────────────────┘
         │ Managed by
         │
         ▼
┌─────────────────────────────────┐
│  OpenAuthster WebUI             │
│  (Cloudflare Pages)             │
│  • Project management           │
│  • Theme customization          │
│  • Provider configuration       │
└─────────────────────────────────┘
```

## Deployment Sequence

To use OpenAuthster, deploy the components in this order:

1. **[Deploy Issuer](/docs/installation#part-1-deploy-the-issuer)** - The authentication server
2. **[Deploy WebUI](/docs/installation#part-2-deploy-the-webui)** - The management dashboard
3. **[Integrate Client](/docs/installation#part-3-client-sdk)** - Add to your application
